# Hermes Retro Lab — Public Beta

This is an experiment: can a locally hosted coding agent independently create a useful **original retro-themed digital product**?

The repository is intentionally **public**. Do not commit personal data, credentials, customer records, API keys, wallet keys, licensed content, or private files.

## Objective / Definition of Done

Hermes can choose the product concept (retro game assets, pixel-art UI, a small game, wallpapers, downloadable tools, templates, or something surprising).

The beta counts as complete only when one product has:
1. Usable source files under `src/` or another documented directory.
2. A packaged, directly usable download under `dist/`.
3. At least one real preview under `previews/`.
4. User instructions and explicit license/provenance notes.
5. Tests or concrete validation checks, plus evidence of their results.
6. A draft product listing and **unvalidated** pricing hypothesis.
7. An accurate update to `state.json`.
8. A reviewable feature branch / pull request. No automatic merge or release.

A brainstorm, generic placeholder, list of ideas, or empty package **does not** count.

## Safety

- Work on this repository only, in a dedicated isolated workspace.
- No edits to Iron Pit, Pocket DM, other projects, production systems, or accounts.
- Never spend funds, mint NFTs, trade cryptocurrency, publish listings, contact customers, or deploy without approval.
- Use original content; no copied sprites, characters, logos, trademarks, or unlicensed assets.
- No fabricated tests, sales, customer interest, traffic, or earnings.
- Keep changes on feature branches for review. No automated push to `main`.
